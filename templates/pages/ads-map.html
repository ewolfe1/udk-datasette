What's represented on this map? ▾

What this map data includes.
This map represents 46.8% of the advertisements included in the collection — over 23,000 advertisers. Advertisements may be missing for a number of reasons, such as no address present in the ad, imprecise address detection by the AI service, or issues georeferencing the supplied address.

How were these addresses identified?
Advertiser names and addresses were extracted by AI tools. Map locations were determined using OpenStreetMap queries based on those extracted addresses.

How reliable is this data?
This map is provided as an overview and introductory search — it is not a substitute for the actual printed data. Inaccurate, imprecise, or missing points may have been introduced through AI address-detection errors, or because automated georeferencing returned no valid result.
